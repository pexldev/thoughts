# Reels Image Brief — I could be wroong
## (AI-Generated Images Stitched to Voice)

---

## What This Is

Each Reel is built by stitching a sequence of AI-generated images that visually narrate the episode story — played over the recorded audio. Think of it as a visual podcast: the voice tells the story, the images show it.

Every image in the sequence should feel like the same world — same style, same character, same palette. The viewer should feel like they're inside one continuous visual story, not looking at random generated images.

---

## Visual Style — Apply To Every Image

- **Illustration style:** Flat cartoon, bold outlines, no complex shading — same style as the mascot character sheet
- **Color palette:** Acid yellow (#D4FF00), near-black (#1A1A1A), warm brown skin tones, muted greys for clothes/objects
- **Background:** Acid yellow as default. Can shift to black for emotional/heavy moments for contrast.
- **Character:** Always the same mascot — bearded Indian guy, round glasses with one cracked lens, messy hair, grey t-shirt. He must look identical across every image in the sequence.
- **No text on images** — the voice handles the words, the image handles the visual
- **No real photos** — everything illustrated

---

## How To Build A Reel Sequence

### Step 1 — Break the script into visual moments
Read the script and identify 6-10 key moments that can be shown visually. Each moment = one image.

### Step 2 — Write a prompt for each image
Use the prompt template below for each moment. Keep the character description identical across all prompts so the style stays consistent.

### Step 3 — Generate, review, reorder
Generate all images, then arrange them in sequence to match the audio narration timing.

### Step 4 — Stitch in your editing tool
Import image sequence + audio, time each image to the narration beat it matches.

---

## ChatGPT Prompt Template (use for every image)

```
Flat cartoon illustration, bold outlines, no complex shading. Acid yellow 
background (#D4FF00). 

Character (always same): Tall bearded Indian man, round glasses with one 
cracked lens, messy dark hair, grey t-shirt, dark trousers. Warm brown 
skin tone. Flat illustration style consistent with the rest of the series.

Scene: [DESCRIBE THE SPECIFIC MOMENT FROM THE SCRIPT]

Mood/expression: [DESCRIBE HOW THE CHARACTER FEELS IN THIS MOMENT]

No text on image. No gradients. No drop shadows. Keep it minimal.
```

## Example — Omelette Episode

Script breakdown → image sequence:

| # | Script moment | Scene to illustrate | Mood |
|---|---|---|---|
| 1 | "I cannot make a perfect omelette" | Character standing at stove, broken omelette in pan, spatula in hand | Staring at it blankly |
| 2 | "Every morning I watch a YouTube video" | Character lying in bed, phone in hand, watching a video | Determined, nodding |
| 3 | "Today is the day. Today I become an omelette person." | Character at stove, confident posture, cracking eggs | Slightly too confident |
| 4 | "And then I flip it. And it breaks." | Broken egg mess in pan, spatula mid-air | Blank stare |
| 5 | "The salt thing is what really broke me" | Character holding salt shaker, looking at it suspiciously | Exhausted |
| 6 | "I eat it anyway." | Character sitting alone at table eating the broken omelette | Resigned but okay |
| 7 | "I've been getting a lot of bad news lately" | Character sitting on floor, surrounded by crumpled papers | Not dramatic, just tired |
| 8 | "Some part of my brain just refuses to accept the data" | Character's head split — one side showing data/charts, other side showing eggs | Confused |
| 9 | "Everyone is doing this" | Multiple versions of the character in different situations — all with broken things | Same blank expression |
| 10 | "The kind that just wakes up and makes eggs." | Character at stove again. New morning. Same pan. Same eggs. | Same expression as image 1 — full circle |

## Sequence Rules

- **First image** should hook immediately — the most visually interesting or funniest moment
- **Last image** should land the emotional close — quieter, more still
- **Vary the framing** — some close-ups (face, hands, object), some wide shots (full character in room)
- **One crack somewhere** in at least one image per sequence — on a mug, phone screen, mirror in background. Ties to brand.
- **Keep backgrounds consistent** — don't switch from yellow to black mid-sequence unless it's intentional for a tonal shift

---

## Common Scene Types To Reuse

| Scene | When to use |
|---|---|
| Character at stove / kitchen | Everyday life moments |
| Character on local train, staring out | Mumbai / commute moments |
| Character at office desk, zoned out | Corporate / work moments |
| Character lying on floor (not dramatic, just done) | Existential moments |
| Character walking, not paying attention | Lost / distracted moments |
| Character with phone, bad news face | Relatable bad news moments |
| Two characters — one ahead, one behind | Comparison / competition moments |

---

## What To Never Do
- Change the character's appearance between images in the same sequence
- Add text or subtitles on the image itself
- Use real photography or photorealistic style
- Make the character look dramatic or over-emotional — he is always understated
- Use more than 2 background colors in one sequence
