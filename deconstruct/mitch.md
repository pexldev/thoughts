## 1st Joke

        I like an escalator, man. Because an escalator can never break. It can only become stairs. All right. There would never be an “escalator temporarily out of order” sign. Only, an “escalator temporarily stairs.” “Sorry for the convenience.”

### Breakdown

- Observation - I like an escalator, man.
- Claim - Because an escalator can never break.
- Redefinition (the genius) - It can only become stairs
- Logical consequence - There would never be an escalator temporarily out of order sign.
- Language attack -  Only an escalator temporarily stairs. Sorry for the convenience.

 * very ordinary premise - I did comedy for a fundraiser once.
