# BEFORE YOU RECORD

**1. Four asides.** Marked above, spread across the runtime. This is the biggest risk in the whole thing — ten minutes in one register is what made ep1 read list-like. Write them on the page; don't plan to find them at the mic.

**2. The refrain map.** "Nobody cares" currently lands:

| block | count |
|---|---|
| 1 · meeting | 1 |
| 2 · deck | 2 |
| 3 · red project | 0 |
| 4 · recruiter | 0 — **deliberate**, she's the one who does care |
| 5 · manage upward | 0 |
| 6 · certification | 0 |
| 7 · number | 1 — the last one, alone |

Four blocks in a row without it in the middle of the episode. Blocks 3 and 5 are where it would naturally land. Your call — but the refrain is the thread the audience hangs on, and right now it goes quiet for about four minutes.

**3. "I could be wrong" at the end of block 3** is a good instinct — the show title as a button. Just check it doesn't spend the title too early, because block 9 is where it actually pays.

**4. What I cleaned up** (spelling only, no wording changed): `inteview` → interview, `Im` → I'm, `DOnt` → Don't, `Its a Wednesday` → It's, `Lock up` → Lock Up, `let's` apostrophe, sentence-start capitals where clearly accidental.

**5. Read it aloud against a timer once.** Only real test of the runtime.
