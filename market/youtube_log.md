# YOUTUBE LOG — the click

A different engine from reels. A reel stop is a **reflex**; a YouTube click is a **decision**, made from a grid of ~12 competing options with a title AND thumbnail both visible. It is a choice against competitors, not a thumb halting.

`source` column separates the two sampling modes — keep both, they answer different questions:
- **organic** — he clicked it himself. His reaction. Skewed, same as the stop log.
- **teardown** — deliberately sampled outlier, logged regardless of whether he'd have clicked.

**The teardown filter is NOT "big video."** A 2M-view video on a 10M-sub channel is normal and teaches nothing. The signal is the **outlier multiple = views ÷ subscriber count.** A video doing 10x its channel's subs is a packaging outlier, and that's where the lesson lives. Log the multiple, not the views.

**Threshold: no pattern offered below 40 entries.** Current: **0**

## Fields

**Tier 1 — always**
| Field | Values |
|---|---|
| Source | organic / teardown |
| Title | verbatim |
| Thumbnail | what is literally in it |
| Views | number |
| Subs | number |
| **Multiple** | views ÷ subs |
| Surface | home / suggested / search / subscriptions / shorts-feed |

**Tier 2 — countable**
| Field | Closed list |
|---|---|
| Title vs thumbnail | **argue / agree** — do they say different things, or the same thing twice? |
| Face in thumbnail | none / face-neutral / face-extreme |
| Thumbnail text | word count |
| Title shape | question / claim / story / list / name-drop |
| Video length | minutes |
| Why he'd click | curiosity-gap / recognition / conflict / person / promise / stakes / title-alone / thumbnail-alone |
| Did he click | yes / no |
| Where he bailed | never-started / <30s / <3min / finished |

**Tier 3 — teardowns only**
| Field | Notes |
|---|---|
| **What it beat** | the other titles on screen when it won the click — CTR is relative, not absolute, and nobody logs this |
| First 30s | what actually happens — cold open / intro / face / claim |
| Top comment | one line: what the video gave people |
| His prediction | logged BEFORE views and subs are revealed |
