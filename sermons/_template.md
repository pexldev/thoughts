# THURSDAY — BEFORE YOU RECORD

- [ ] **Four asides written on the page.** Break character — *"ohh that's a bad one"*, *"my dad will kill me."* Spread across the runtime. Don't plan to find them at the mic; that's what made ep1 read list-like.
- [ ] **Refrain map checked** — no gap longer than two blocks.
- [ ] **Second person holds.** Search the script for "I" — it should appear exactly twice, both in block 9.
- [ ] **No advice anywhere.** Any line that tells them how to live gets cut to PARKED. Permission, never advice.
- [ ] **Runner appears ~3 times.** Not six.
- [ ] **Read aloud against a timer.** Only real test of runtime.
