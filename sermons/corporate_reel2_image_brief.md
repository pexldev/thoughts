## Colour line

**Scene colour: Sarkari green `#3F6B4F` · Anchor C (yellow hero object) · both held for the whole reel.**

Sarkari green because the entire block is institutional — a certification, an exam hall, a manager's cabin. Anchor C because it gives the reel its one structural idea:

**The yellow object is always the thing he's being told to chase.** It changes across the seven frames — certificate → interview door → the machine's screen → the manager's pointing hand → the promotion list → his phone → the ring light. Same anchor, same colour, one silent arc. The last two frames are where the yellow thing finally becomes something that's actually his.

Colours per frame: yellow + black + sarkari green + skin + grey tee = **5**, one under the cap.

---

## The loop

**Frame A and Frame G are the same room, same angle, same desk.** Only two things change: the certificate goes face-down, and the glowing object becomes the ring light. The reel loops almost invisibly *and* the punch still lands on a new picture — which the standard "opening image = closing image" rule in [fixed_assets.md](fixed_assets.md) §2 would have cost us. Deliberate departure, flagged.

**G is the CTA frame.** Bottom 20% must stay clear of black elements or the black CTA text disappears into the desk.

# TWO PIPELINE RISKS — read before you render

**1 · `prep-images.js` snaps the yellow.** It finds the dominant *yellow* and pushes it to exactly `#F2FF00` so full-bleed cuts don't flicker. These frames are anchor C — the yellow is a glowing object plus its light pool, maybe 20–25% of the frame, not 75%. It should still find it, but **check the snapped output before rendering**; this is the first batch that isn't yellow-dominant.

**2 · The brand flip will look different.** `_flip` swaps yellow and black — built for near-all-yellow frames. On a sarkari green room the flip is a much smaller change and may read as a glitch rather than a slam. If it does, set `FLASH_BEATS = [0]` so the flip is purely an opener, per [reel-cut.md](../.claude/commands/reel-cut.md).
