### Verbs

| Word     | Meaning                | Usage                                |
| -------- | ---------------------- | ------------------------------------ |
| nosotros | we                     | “we” group including yourself        |
| vosotros | you all                | informal “you guys” *(mostly Spain)* |
| ellos    | they (men/mixed group) | talking about other people           |
| ustedes  | you all                | formal/plural “you all”              |


For regular -AR verbs like hablar (to speak), the present tense table is:

| Subject                 | Ending | Example  |
| ----------------------- | ------ | -------- |
| yo                      | -o     | hablo    |
| tú                      | -as    | hablas   |
| él / ella / usted       | -a     | habla    |
| nosotros / nosotras     | -amos  | hablamos |
| vosotros / vosotras     | -áis   | habláis  |
| ellos / ellas / ustedes | -an    | hablan   |


For regular -ER verbs bhai (like comer = to eat), the endings are:

| Subject           | Ending | Example (comer) |
| ----------------- | ------ | --------------- |
| yo                | -o     | como            |
| tú                | -es    | comes           |
| él / ella / usted | -e     | come            |
| nosotros          | -emos  | comemos         |
| vosotros          | -éis   | coméis          |
| ellos / ustedes   | -en    | comen           |


| Spanish Verb | Meaning in English                    |
| ------------ | ------------------------------------- |
| hablar       | to speak / to talk                    |
| comer        | to eat                                |
| beber        | to drink                              |
| ir           | to go                                 |
| tener        | to have                               |
| querer       | to want / to love                     |
| hacer        | to do / to make                       |
| gustar       | to like *(literally: to be pleasing)* |
